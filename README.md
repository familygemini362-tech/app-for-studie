# Soft Glass Study Tracker

เว็บแอปติดตามการเรียน ที่รวม **To-Do List** + **ตารางส่งงาน** + **ปฏิทิน** + **ตารางเรียน** + **สถิติ/คะแนน** ไว้ในที่เดียว ออกแบบด้วยสไตล์ Soft Glassmorphism (กระจกฝ้า + นูนต่ำ)

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (Chrome / Edge แนะนำ)
2. ข้อมูลทั้งหมดถูกบันทึกในเครื่อง (LocalStorage) ไม่ต้องมี Server

## แท็บหลัก (4 แท็บ)

| แท็บ | ความสามารถ |
|------|------------|
| งาน | To-Do ทั่วไป: เพิ่ม / ขีดฆ่า / แก้ไข / ลบ / ลากเรียง / กรอง / ค้นหา |
| ส่งงาน | ติดตามงานส่ง: วิชา+สี, วัน/เวลาส่ง, ประเภท, งานซ้ำ, งานย่อย (Subtask), หมายเหตุ, แนบรูป, ค้นหา, จัดกลุ่มสถานะ |
| ปฏิทิน | มุมมองรายเดือน (จุดสีวิชา, ลากงานไปวันอื่นเพื่อเลื่อนกำหนดส่ง) + ตารางเรียนรายสัปดาห์ |
| สถิติ | การ์ดสรุป (งานรวม/ส่งแล้ว/เลยกำหนด/อัตราส่ง), กราฟงานต่อวิชา, ภาระงาน 4 สัปดาห์, บันทึกคะแนนรายวิชา |

## ฟีเจอร์เด่น

- **แจ้งเตือนจริง** — กดกระดิ่งที่มุมบนขวาเพื่อเปิด Browser Notification (แจ้งงานเลยกำหนด/ส่งวันนี้, เช็คทุก 30 นาที)
- **งานซ้ำ (Recurring)** — เลือก รายวัน/รายสัปดาห์/รายเดือน เมื่อติ๊กว่าส่งแล้ว ระบบสร้างงานรอบถัดไปให้อัตโนมัติ
- **งานย่อย (Subtask)** — แตกงานใหญ่เป็นขั้นย่อย พร้อมแถบความคืบหน้าในรายการ
- **ลากปฏิทิน** — ลากรายการงานในแผง "งานที่ต้องส่ง" ไปวางบนวันอื่นในปฏิทินเพื่อเลื่อนกำหนดส่ง
- **ตารางเรียน** — เพิ่มคาบเรียน (วิชา/วัน/เวลา) แสดงในมุมมองตารางเรียน และในรายละเอียดของแต่ละวัน
- **บันทึกคะแนน** — เก็บคะแนนสอบ/ส่งงาน คำนวณค่าเฉลี่ยรายวิชาอัตโนมัติ
- **Export/Import** — ปุ่มดาวน์โหลด/อัปโหลดที่มุมบนขวา สำรอง-กู้คืนข้อมูลทั้งหมดเป็นไฟล์ JSON
- **แก้ไขวิชา** — เปลี่ยนชื่อ/สีวิชาได้ ไม่ต้องลบทิ้ง
- **Dark Mode** — ปุ่มพระจันทร์/อาทิตย์ จำค่าไว้
- รองรับมือถือ (Responsive)

## โครงสร้างข้อมูล (LocalStorage)

| กุญแจ | เนื้อหา |
|-------|---------|
| `todos` | รายการงานทั่วไป |
| `todo-assignments` | งานส่ง (วิชา, วัน/เวลาส่ง, ประเภท, repeat, subtasks, รูป, สถานะ) |
| `todo-subjects` | วิชา (ชื่อ + สี) |
| `todo-timetable` | คาบเรียน (วิชา, วัน, เวลาเริ่ม-เลิก) |
| `todo-grades` | คะแนน (วิชา, ชื่อรายการ, คะแนน/เต็ม) |
| `todo-theme` | โหมดธีม |

## หมายเหตุ

- รูปภาพถูกบีบอัด ~900px / JPEG 0.7 กัน localStorage เกิน (จำกัด ~5MB)
- การลบวิชา งานที่ผูกอยู่จะแสดงเป็น "ไม่มีวิชา" (ข้อมูลไม่ถูกลบ)
- ไฟล์ Import ต้องเป็นไฟล์ที่ Export จากแอปนี้เท่านั้น
- Notification อาจต้องอนุญาตในเบราว์เซอร์เมื่อใช้ครั้งแรก
